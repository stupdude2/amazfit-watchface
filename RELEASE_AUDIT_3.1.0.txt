Upgrade behavior:
An existing installation retains the same app UUID and persistence key. The
v16 WatchfaceSettings layout is unchanged, so existing colors, slots, label
visibility, bar modes, step goal, temperature unit, clock/background colors,
time format, wrist raise mode, and language are read without migration or reset.
New Time Zone selections default independently to Local Time and are only used
when a user explicitly selects the Time Zone slot option.
